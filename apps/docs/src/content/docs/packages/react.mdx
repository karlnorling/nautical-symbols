## Installation

```sh
npm install @nautical-symbols/react
```

## Named components

Each symbol is available as a PascalCase named export derived from its code and name.

```tsx
import { FlagAlfa } from '@nautical-symbols/react';

export function App() {
  return <FlagAlfa width={64} height={64} title="A (Alfa)" />;
}
```

The component name pattern is `{Code}{Name}` — e.g. `Substitute1`, `ChartCanBuoyRed`, `Pennant1`, `TopmarkTwoConeUpBlack`.

## SymbolById component

Use `SymbolById` when the symbol is determined at runtime.

```tsx
import { SymbolById } from '@nautical-symbols/react';

export function DynamicSign({ id }: { id: string }) {
  return <SymbolById id={id} width={64} height={64} title="Nautical symbol" />;
}
```

## Props

### Named component props

| Prop          | Type     | Required | Description                                      |
|---------------|----------|----------|--------------------------------------------------|
| `width`       | `number` | No       | Width in pixels. Defaults to the SVG's intrinsic width. |
| `height`      | `number` | No       | Height in pixels. Defaults to the SVG's intrinsic height. |
| `title`       | `string` | No       | Sets the SVG `<title>` element for screen readers. |
| `description` | `string` | No       | Sets the SVG `<desc>` element for additional context. |

### SymbolById additional prop

| Prop | Type     | Required | Description                                |
|------|----------|----------|--------------------------------------------|
| `id` | `string` | Yes      | Symbol ID, e.g. `"flag-alfa"`.     |

All named component props also apply to `SymbolById`.

## TypeScript

The package ships its own type declarations. Import the prop type if you need it:

```ts
import type { SymbolProps } from '@nautical-symbols/react';
```

## Accessibility

Every component renders an `<svg>` with `role="img"` and an `aria-labelledby` attribute pointing to the generated `<title>` and `<desc>` elements, which default to the symbol name. Passing `aria-label` labels the `<svg>` directly instead. Ids are unique per instance, so the same symbol can appear any number of times on a page.

```tsx
// Fully accessible
<FlagAlfa
  width={64}
  title="A (Alfa)"
  description="Green symbol showing a running figure with directional arrow"
/>
```

Decorative symbols that are already labelled by surrounding text should omit `title` and add `aria-hidden="true"`.
