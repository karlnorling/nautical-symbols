## Why Nautical Symbols?

Signal flags are the International Code of Signals (ICS) flag set: 26 letter flags, each with a
standard single-flag meaning, the numeral pennants, the NATO numeral flags, the answer pennant and
the substitutes that repeat a flag within one hoist. Chart symbols are the INT 1 and ECDIS
pictograms for buoys, beacons, topmarks, lights, dangers and areas on nautical charts.
This library packages all 273
symbols as accessible, fully typed components ready to drop into any project.
