# @nautical-symbols/elements

Accessible Web Components (Custom Elements) for the **International Code of Signals** flags and **nautical chart** symbols — framework-agnostic, zero runtime dependencies.

[![npm](https://img.shields.io/npm/v/@nautical-symbols/elements)](https://www.npmjs.com/package/@nautical-symbols/elements)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/karlnorling/nautical-symbols/blob/main/LICENSE)

---

## Installation

```sh
npm install @nautical-symbols/elements
# or
yarn add @nautical-symbols/elements
```

---

## Usage

### Register all elements

```ts
import { defineCustomElements } from '@nautical-symbols/elements';
defineCustomElements();
```

Then use the elements in HTML:

```html
<!-- Generic element — render any symbol by ID -->
<nautical-symbol symbol-id="flag-alfa" width="64"></nautical-symbol>

<!-- Named elements (generated by yarn generate) -->
<nautical-flag-alfa width="64"></nautical-flag-alfa>
<nautical-chart-can-buoy-red width="64"></nautical-chart-can-buoy-red>
```

### Custom prefix

Avoid tag-name conflicts with other libraries by passing a custom prefix:

```ts
defineCustomElements('care');
// Registers: care-symbol, care-flag-alfa, care-chart-can-buoy-red, …
```

## Attributes

All elements and `<nautical-symbol>` accept the same attributes:

| Attribute     | Default              | Description                                                   |
| ------------- | -------------------- | ------------------------------------------------------------- |
| `symbol-id`   | —                    | Symbol slug ID (`<nautical-symbol>` only), e.g. `"flag-alfa"` |
| `title`       | Symbol name          | Accessible title (`<title>` inside SVG)                       |
| `description` | Symbol description   | Accessible description (`<desc>` inside SVG)                  |
| `aria-label`  | —                    | Labels the `<svg>` directly instead of via title/description  |
| `width`       | SVG intrinsic width  | Forwarded to the `<svg>` width attribute                      |
| `height`      | SVG intrinsic height | Forwarded to the `<svg>` height attribute                     |

All attributes are reactive — changing them re-renders the SVG.

## Framework usage

### React

```tsx
// React treats unknown elements as HTML. Add a JSX type declaration if needed.
declare namespace JSX {
  interface IntrinsicElements {
    'nautical-symbol': React.HTMLAttributes<HTMLElement> & {
      'symbol-id'?: string;
      width?: string | number;
      height?: string | number;
    };
  }
}

<nautical-symbol symbol-id="flag-alfa" width="64" />;
```

### Vue 3

```vue
<template>
  <nautical-symbol symbol-id="flag-alfa" width="64" />
</template>
```

## Accessibility

Each element renders with `role="img"` and `aria-labelledby` pointing to a `<title>` and `<desc>` injected inside the SVG. An `aria-label` attribute on the element labels the `<svg>` directly instead. Ids are unique per element, so the same symbol can appear any number of times on a page. The host element gets `display: contents` so it is transparent to layout.
