Why Nautical Symbols?

Section titled “Why Nautical Symbols?”

Signal flags are the International Code of Signals (ICS) flag set: 26 letter flags, each with a standard single-flag meaning, the numeral pennants, the NATO numeral flags, the answer pennant and the substitutes that repeat a flag within one hoist. Chart symbols are the INT 1 and ECDIS pictograms for buoys, beacons, topmarks, lights, dangers and areas on nautical charts. Ensigns are the flags vessels fly to show their nationality: civil, naval and coast guard ensigns, and the jacks flown at the bow, per country. This library packages all 545 symbols as accessible, fully typed components ready to drop into any project.

React & Vue 3

Named components and a SymbolById helper for dynamic rendering. Tree-shakeable — only the symbols you import end up in your bundle.

Web Components

Framework-agnostic Custom Elements. Works with Angular, Svelte, plain HTML — anywhere.

CSS Sprite

Zero JavaScript option. Display any symbol with a single class and no JS runtime.

Accessible by default

Every component renders with role="img", aria-labelledby, <title>, and <desc> inside the SVG.
