## Installation

```sh
npm install @nautical-symbols/assets
```

## Directory layout

Assets are organised by category and symbol code under the `assets/` directory:

```
assets/
├── letter-flags/
│   └── flag-alfa/
│       ├── flag-alfa.svg
│       ├── flag-alfa_240x240.png
│       ├── flag-alfa_512x512.png
│       ├── flag-alfa_768x768.png
│       ├── flag-alfa_1024x1024.png
│       ├── flag-alfa_2048x2048.png
│       ├── flag-alfa_240x240.jpg
│       ├── flag-alfa_240x240.webp
│       └── ...
├── number-pennants/
├── nato-number-flags/
├── special-pennants/
└── … one directory per category
```

## Available sizes

| Size    | Formats      |
|---------|--------------|
| SVG     | `.svg`       |
| 240 px  | `.png`, `.webp` |
| 512 px  | `.png`, `.webp` |
| 768 px  | `.png`, `.webp` |
| 1024 px | `.png`, `.webp` |
| 2048 px | `.png`, `.webp` |

## Import by path

Reference a specific asset directly in your bundler:

```ts
import alfaSvg from '@nautical-symbols/assets/assets/letter-flags/flag-alfa/flag-alfa.svg';
import alfaPng from '@nautical-symbols/assets/assets/letter-flags/flag-alfa/flag-alfa_512x512.png';
```

## Resolve paths via the core API

Use `@nautical-symbols/core` to look up asset paths programmatically without hardcoding directory structure:

```ts
import { getSymbol } from '@nautical-symbols/core';

const symbol = getSymbol('flag-alfa');

// SVG path
const svgPath = symbol.assets.svg;
// → 'letter-flags/flag-alfa/flag-alfa.svg'

// PNG at a specific size
const png512 = symbol.assets.png[512];
// → 'letter-flags/flag-alfa/flag-alfa_512x512.png'

// WebP at a specific size
const webp240 = symbol.assets.webp[240];
// → 'letter-flags/flag-alfa/flag-alfa_240x240.webp'
```

Combine with a base URL for use in `<img>` tags:

```ts
const baseUrl = 'https://cdn.example.com/nautical-symbols/assets/';
const src = baseUrl + symbol.assets.png[512];
```
